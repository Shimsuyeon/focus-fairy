# 🧚‍♀️ 집중요정 크롬 익스텐션

Slack에 들어가지 않고 툴바 팝업에서 집중 세션을 시작·일시정지·재개·종료하고, 같은 화면에서 이번 달 기록을 봐요. 기록은 Slack 명령어와 같은 KV에 저장되므로 어디서 시작하든 서로 동기화돼요.

## 설치 (개발자 모드)

1. `chrome://extensions` 접속 → 오른쪽 위 **개발자 모드** 켜기
2. **압축해제된 확장 프로그램을 로드합니다** → 이 `extension/` 폴더 선택
3. 툴바의 퍼즐 아이콘에서 집중요정을 고정

## 연결

1. Slack 집중요정 **홈 탭 → 크롬 익스텐션 연결** 버튼 (또는 `/settings extension`)
2. 모달에 표시된 `ff_...` 토큰을 익스텐션 팝업에 붙여넣기

토큰을 재발급하면 이전 토큰은 즉시 무효화돼요.

### 여러 워크스페이스

워크스페이스마다 토큰을 발급해서 팝업 위쪽 드롭다운의 **＋ 워크스페이스 추가**로 등록하면 돼요. 드롭다운으로 전환하고, ⚙︎ 에서 지금 워크스페이스의 토큰 변경·연결 해제를 할 수 있어요.

- 세션·채널 선택은 워크스페이스별로 따로 저장돼요.
- 배지는 지금 보고 있는 워크스페이스를 우선 표시하고, 그곳이 쉬는 중이면 집중 중인 다른 워크스페이스를 보여줘요. 드롭다운에서도 ⏳/🌙 아이콘으로 표시돼요.
- 단축키는 지금 선택된 워크스페이스에 적용돼요.

## 기능

- 팝업 왼쪽: 큰 타이머, 카테고리 아이콘 버튼(집중 중에 누르면 바로 변경), 계획 수정, 오늘 함께 집중한 팀원 현황, 쉬어가기·종료
- 팝업 오른쪽: 이번 달의 나무(목표에 가까워질수록 자라고, 집중한 날마다 열매), 요정의 한마디, 일 평균·최고의 날, 일별/누적 그래프, 카테고리 비율
- 툴바 배지: 집중 시간 표시 (보라 = 집중 중, 주황 = 일시정지, `!` = 토큰 오류)
- 단축키: `⌥⇧F` 팝업 열기, `⌥⇧S` 시작/일시정지/재개 토글 (`chrome://extensions/shortcuts` 에서 변경)
- 임계값(기본 6시간)을 넘는 세션은 종료 전에 확인하거나 시간을 직접 입력

## 채널 메시지

시작·종료 메시지를 올릴 채널은 팝업에서 골라요. 목록은 **그 워크스페이스에서 Slack `/start` 를 한 적 있는 채널**(최근 10개)이고, 기본값은 마지막으로 `/start` 한 채널이에요. **💤 채널에 안 올리기**를 고르면 기록만 돼요.

봇에 `channels:read` 권한을 추가하지 않으려고 슬래시 커맨드에 담겨 오는 채널 이름을 기억하는 방식이에요. 그래서 기존 워크스페이스는 재설치가 필요 없어요.

## 로컬 개발

`npm run dev` 로 워커를 띄운 뒤 팝업 설정의 **서버 주소**를 `http://localhost:8787` 로 바꾸면 돼요.

## API

모든 요청에 `Authorization: Bearer <token>` 헤더가 필요해요.

| 메서드 | 경로                   | 설명                                                                       |
| ------ | ---------------------- | -------------------------------------------------------------------------- |
| GET    | `/api/session`         | 워크스페이스·사용자 이름, 세션 상태, 오늘 누적, 최근 채널, 카테고리        |
| POST   | `/api/session/start`   | `{ label?, tag?, channelId? }` — `null`이면 채널에 안 올림                 |
| POST   | `/api/session/pause`   |                                                                            |
| POST   | `/api/session/resume`  |                                                                            |
| POST   | `/api/session/end`     | `{ duration?: ms, confirm?: boolean }` — 임계값 초과 시 `needsConfirm` 응답 |
| POST   | `/api/session/update`  | `{ tag?, label? }` — 진행 중 세션의 카테고리·계획 수정                     |
| GET    | `/api/team`            | 오늘 집중한 팀원과 현재 상태 (계획 내용은 빼고 카테고리만)                 |
| GET    | `/api/stats?month=`    | 월별 날짜별 집중 시간, 카테고리별 합계, 월 목표                            |
| POST   | `/api/goal`            | `{ hours }` — 월 목표 시간, 0이면 해제                                     |
