# 🧚‍♀️ 집중요정 크롬 익스텐션

Slack에 들어가지 않고 툴바에서 집중 세션을 시작·일시정지·재개·종료해요. 기록은 Slack 명령어와 같은 KV에 저장되므로 어디서 시작하든 서로 동기화돼요.

## 설치 (개발자 모드)

1. `chrome://extensions` 접속 → 오른쪽 위 **개발자 모드** 켜기
2. **압축해제된 확장 프로그램을 로드합니다** → 이 `extension/` 폴더 선택
3. 툴바의 퍼즐 아이콘에서 집중요정을 고정

## 연결

1. Slack 집중요정 **홈 탭 → 크롬 익스텐션 연결** 버튼 (또는 `/settings extension`)
2. 모달에 표시된 `ff_...` 토큰을 익스텐션 팝업에 붙여넣기

토큰을 재발급하면 이전 토큰은 즉시 무효화돼요.

## 기능

- 팝업: 계획/카테고리 입력 후 시작, 일시정지·재개·종료, 실시간 타이머, 오늘 누적
- 툴바 배지: 집중 시간 표시 (보라 = 집중 중, 주황 = 일시정지, `!` = 토큰 오류)
- 단축키: `⌥⇧F` 팝업 열기, `⌥⇧S` 시작/일시정지/재개 토글 (`chrome://extensions/shortcuts` 에서 변경)
- 임계값(기본 6시간)을 넘는 세션은 종료 전에 확인하거나 시간을 직접 입력

## 채널 메시지

익스텐션에는 채널 컨텍스트가 없어서, **마지막으로 Slack에서 `/start` 한 채널**에 시작·종료 메시지가 올라가요. 한 번도 `/start` 한 적이 없다면 기록만 되고 메시지는 올라가지 않아요.

## 로컬 개발

`npm run dev` 로 워커를 띄운 뒤 팝업 설정의 **서버 주소**를 `http://localhost:8787` 로 바꾸면 돼요.

## API

모든 요청에 `Authorization: Bearer <token>` 헤더가 필요해요.

| 메서드 | 경로                   | 설명                                                                       |
| ------ | ---------------------- | -------------------------------------------------------------------------- |
| GET    | `/api/session`         | 현재 세션 상태, 오늘 누적, 카테고리 목록                                   |
| POST   | `/api/session/start`   | `{ label?, tag? }`                                                         |
| POST   | `/api/session/pause`   |                                                                            |
| POST   | `/api/session/resume`  |                                                                            |
| POST   | `/api/session/end`     | `{ duration?: ms, confirm?: boolean }` — 임계값 초과 시 `needsConfirm` 응답 |
