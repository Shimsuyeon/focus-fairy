집중요정의 **App Home 탭**은 Slack 사이드바에서 봇 이름을 클릭했을 때 보이는 영구 화면이에요. 본인의 집중 상태와 통계를 한눈에 확인할 수 있고, 자주 쓰는 설정으로 빠르게 진입할 수 있어요.

## 열어보는 방법

1. Slack 사이드바에서 **focus-fairy(집중요정)** 를 클릭
2. 상단 탭에서 **홈** 선택

탭을 열 때마다 최신 데이터로 자동 갱신돼요.

## 보이는 정보

| 영역 | 내용 |
|---|---|
| 인사말 | 본인 표시 이름 |
| 현재 상태 | 집중 중 · 일시정지 중 · 쉬는 중 (현재 진행 중인 세션이 있으면 경과 시간과 계획도 함께 표시) |
| 오늘 | 오늘 누적 집중 시간 + 세션 횟수 |
| 이번 주 | 이번 주 누적 + 팀 내 랭킹 |
| 전체 누적 | 봇 설치 이후 모든 집중 시간 합계 |
| 빠른 진입 | Slack status 동기화, 워크스페이스 설정, 도움말 모달 |

집중 기록이 한 번도 없는 신규 사용자에겐 통계 대신 **온보딩 카드**가 표시돼요 — 어떤 명령어로 시작할지 단계별로 안내합니다.

## 채널 워크플로와의 관계

App Home은 **정보·진입점** 용도, 작업 채널의 슬래시 명령어와 [세션 컨트롤 패널](/commands/start/#컨트롤-패널)이 **액션** 용도로 역할을 나눠요.

- 집중 시작/일시정지/재개/종료 → 작업 채널에서 `/start` + ephemeral 컨트롤 패널
- 통계 조회·신규 가이드·설정 진입 → App Home

App Home에서 일시정지/재개/종료 버튼을 두지 않은 이유는, App Home은 채널 컨텍스트(어느 채널에 공개 메시지를 띄울지)를 알 수 없기 때문이에요.

:::tip
홈 탭에서 보는 통계는 항상 본인 것만이에요. 팀 전체 랭킹은 [`/weekly`](/commands/weekly/), 팀의 오늘 현황은 [`/today`](/commands/today/) 명령어로 채널에서 볼 수 있어요.
:::

## 갱신 주기

- **자동 갱신**: 사용자가 홈 탭을 열 때마다 (Slack의 `app_home_opened` 이벤트)
- **수동 갱신 없음**: 통계가 갱신되지 않으면 탭을 한 번 닫았다가 다시 열어주세요. 다른 탭(메시지/정보)으로 이동했다가 홈으로 돌아와도 갱신돼요.

## 봇 운영자 안내 (자체 설치)

집중요정을 직접 운영하는 경우 App Home을 활성화하려면 Slack 앱 설정에서 다음을 추가하세요.

1. **App Home** 섹션 → "Home Tab" 토글을 켭니다.
2. **Event Subscriptions** 섹션:
   - "Enable Events" 토글 ON
   - Request URL: `https://<your-worker>/slack/events`
   - "Subscribe to bot events" → `app_home_opened` 추가
3. 변경 사항 저장 후 워크스페이스에 앱을 **재설치(reinstall)** 해서 새 권한/이벤트 구독이 반영되도록 합니다.

홈 뷰 발행에는 추가 권한이 필요 없어요 (기존 `chat:write`, `users:read`로 충분).
