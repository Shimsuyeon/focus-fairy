매번 Slack에 들어가 `/start`, `/end` 를 치기 번거롭다면 **집중요정 크롬 익스텐션**을 써보세요. 툴바 아이콘을 누르면 열리는 팝업에서 세션을 시작·일시정지·종료하고, 오늘 함께 집중한 팀원과 이번 달 통계를 한 화면에서 볼 수 있어요.

기록은 Slack 명령어와 같은 곳에 저장돼요. 익스텐션에서 시작하고 Slack에서 `/end` 해도 되고, 그 반대도 돼요.

## 설치하기

아직 크롬 웹스토어에는 올라가 있지 않아서 **개발자 모드**로 설치해요.

1. [GitHub 저장소](https://github.com/Shimsuyeon/focus-fairy)를 내려받아요. **Code → Download ZIP** 후 압축을 풀거나 `git clone` 하면 돼요.
2. 크롬 주소창에 `chrome://extensions` 를 입력하고, 오른쪽 위 **개발자 모드**를 켜요.
3. **압축해제된 확장 프로그램을 로드합니다** 를 누르고 저장소 안의 `extension/` 폴더를 선택해요.
4. 툴바의 퍼즐 아이콘에서 집중요정을 **고정**해두면 편해요.

## 워크스페이스 연결하기

익스텐션은 Slack 계정 대신 **개인 연결 토큰**으로 본인을 확인해요.

1. Slack 사이드바에서 집중요정 **홈 탭 → 크롬 익스텐션 연결** 버튼을 누르거나, 아무 채널에서 `/settings extension` 을 입력해요.
2. 모달에 표시된 `ff_...` 토큰을 복사해요.
3. 익스텐션 팝업을 열고 토큰을 붙여넣은 뒤 **연결하기**를 눌러요.

:::caution
토큰은 비밀번호처럼 다뤄주세요. 다른 사람에게 공유하지 마세요. 토큰은 모달에서 한 번만 보여주고, 서버에는 원본이 아닌 해시만 저장돼요.

토큰을 다시 발급하면 **이전 토큰은 바로 무효**가 돼요. 토큰이 노출된 것 같으면 다시 발급하면 돼요.
:::

### 여러 워크스페이스 쓰기

여러 Slack 워크스페이스에서 집중요정을 쓰고 있다면, 워크스페이스마다 토큰을 발급해서 팝업 위쪽 드롭다운의 **＋ 워크스페이스 추가**로 등록하면 돼요.

- 드롭다운으로 워크스페이스를 전환해요. 다른 워크스페이스가 집중 중이면 🟢, 쉬어가는 중이면 🟠 가 붙어요.
- ⚙︎ 버튼에서 지금 워크스페이스의 토큰 변경이나 연결 해제를 할 수 있어요.
- 세션과 채널 선택은 워크스페이스마다 따로 저장돼요.

## 팝업 둘러보기

### 왼쪽 — 세션 컨트롤

| 영역 | 내용 |
|---|---|
| 상태 · 시간 | 집중 중이면 이번 세션 시간, 쉬는 중이면 오늘 누적 시간을 크게 보여줘요 |
| 수정하기 | 진행 중인 세션의 계획을 고쳐요 |
| 카테고리 | 📚 공부 · 💻 사이드 · 📖 독서 · 🏃 운동 · ✨ 기타. 쉬는 중엔 시작할 카테고리를 고르고, 집중 중에 누르면 바로 바뀌어요 |
| 계획 · 채널 | 시작 전에 계획을 적고, 시작·종료 메시지를 올릴 채널을 골라요 |
| 오늘 함께 집중 | 오늘 집중한 팀원과 지금 상태, 오늘 시간 (집중 중인 사람이 먼저) |
| 버튼 | 🧚 집중 시작 / ☕ 쉬어가기 / 🪄 다시 집중 / 집중 종료 |

:::note
팀원 목록에는 **카테고리만** 보이고, 각자 적은 계획 내용은 보이지 않아요.
:::

### 오른쪽 — 이번 달 통계

| 영역 | 내용 |
|---|---|
| 이번 달 집중 | 이번 달 누적 시간과 월 목표 진행률. 막대의 세로선은 오늘까지 목표 페이스예요 |
| 오늘 · 일 평균 | 오늘 집중 시간, 이번 달 하루 평균 |
| 목표까지 하루 | 남은 날 동안 하루에 몇 시간씩 하면 목표를 채우는지. 마우스를 올리면 남은 날, 채울 시간, 어제까지 페이스를 보여줘요 |
| 집중한 날 | 이번 달 집중한 날 수와 🔥 연속 기록 |
| 그래프 | **누적** — 실제 누적과 목표 페이스(점선), **일별** — 날짜별 막대. 마우스를 올리면 그날 값이 나와요 |
| 카테고리 | 이번 달 카테고리별 시간과 비율 |

‹ › 버튼으로 지난 달 통계도 볼 수 있어요.

### 월 목표 정하기

오른쪽 위 **목표 설정**을 누르고 이번 달 목표 시간(예: `80`)을 입력해요. 목표를 정하면 진행률, 목표까지 하루, 그래프의 목표 페이스가 함께 표시돼요. `0` 을 입력하면 목표가 해제돼요.

## 채널 메시지

익스텐션에서 시작·종료해도 Slack 채널에 평소처럼 메시지가 올라가요. 올릴 채널은 팝업에서 골라요.

- 목록에는 **그 워크스페이스에서 `/start` 를 한 적 있는 채널**(최근 10개)이 나와요. 처음이라면 원하는 채널에서 `/start` 를 한 번 해주세요.
- 기본값은 마지막으로 `/start` 한 채널이에요.
- **💤 채널에 안 올리기**를 고르면 메시지 없이 기록만 돼요.

:::tip
봇에 채널 목록 권한(`channels:read`)을 추가하지 않으려고 이렇게 만들었어요. 그래서 이미 설치된 워크스페이스는 **재설치 없이** 바로 쓸 수 있어요.
:::

## 툴바 배지와 단축키

- 툴바 아이콘 배지에 집중 시간이 표시돼요 (초록 = 집중 중, 주황 = 쉬어가는 중, `!` = 토큰 확인 필요).
- `⌥⇧F` (Windows: `Alt+Shift+F`) — 팝업 열기
- `⌥⇧S` (Windows: `Alt+Shift+S`) — 팝업을 열지 않고 시작 / 쉬어가기 / 다시 집중
- 단축키는 `chrome://extensions/shortcuts` 에서 바꿀 수 있어요.

## 자주 묻는 질문

**Slack에서 시작한 세션도 익스텐션에 보이나요?**
네. 팝업을 열 때마다, 그리고 5분마다 서버와 동기화해요.

**6시간 넘게 켜둔 세션을 종료하면요?**
Slack의 [`/end`](/commands/end/) 와 같아요. 워크스페이스의 자동 기록 임계값(기본 6시간, `/settings` 에서 변경)을 넘으면 그대로 기록할지 확인하고, 실제 집중 시간을 직접 입력할 수도 있어요.

**Slack status 동기화도 되나요?**
네. [`/settings sync`](/settings/sync/) 로 연결해두면 익스텐션에서 시작·종료할 때도 status가 바뀌어요.
