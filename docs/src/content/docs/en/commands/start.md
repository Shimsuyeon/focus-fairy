Starts a focus session. Pass a task name so it shows up in your stats later.

```
/start [task name]
```

If another Slack app intercepts the command, use `/fstart` as a drop-in alias. See [command conflict workaround](/en/commands/aliases/) for details. A personal control panel (pause / end / stats buttons) is also delivered as an ephemeral message after starting.
