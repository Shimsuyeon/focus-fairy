## 1. Add to your Slack workspace

Click the [install link](https://focus-fairy.suyeonshim.workers.dev/slack/oauth/install) to add Focus Fairy to your workspace.
Once permissions are granted, you can use the commands from any channel.

## 2. Start your first session

In a channel or DM, run:

```
/start [task name]
```

Focus Fairy starts the timer. When you're done, run `/end` to wrap up.

## 3. Check your stats

- `/mystats` — Your cumulative focus time and patterns
- `/today` — Today's team-wide focus activity
- `/weekly` — This week's summary
