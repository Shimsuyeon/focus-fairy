## 1. Slack 워크스페이스에 추가하기

[설치 링크](https://focus-fairy.suyeonshim.workers.dev/slack/oauth/install)를 눌러 집중요정을 워크스페이스에 추가하세요.
권한 승인이 끝나면 채널에서 명령어를 바로 사용할 수 있어요.

## 2. 첫 집중 세션 시작하기

채널이나 봇 DM에서 다음 명령어를 입력해보세요.

```
/start 집중할 작업 이름
```

`/start`를 입력하면 집중요정이 타이머를 켜고, 끝내고 싶을 때 `/end`를 입력하면 세션이 마무리돼요.

## 3. 통계 확인하기

- `/mystats` — 내 누적 집중 시간과 패턴
- `/today` — 오늘 팀 전체 집중 현황
- `/weekly` — 이번 주 요약
