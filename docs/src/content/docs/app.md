폰에서 Slack을 열고 `/start` 를 치기 번거롭다면 **집중요정 웹앱**을 홈 화면에 추가해보세요. 앱스토어 설치 없이 아이콘을 누르면 바로 열리고, [크롬 익스텐션](/extension/)과 같은 화면으로 세션을 시작·일시정지·종료하고 오늘 함께 집중한 팀원과 이번 달 통계를 볼 수 있어요.

기록은 Slack 명령어, 익스텐션과 같은 곳에 저장돼요. 웹앱에서 시작하고 Slack이나 익스텐션에서 종료해도 돼요.

## 연결하기

Slack 사이드바의 집중요정 **홈 탭 → 폰 웹앱 연결** 버튼을 누르거나, 아무 채널에서 `/settings app` 을 입력해요. 모달에 **📱 웹앱 열기** 버튼과 **연결 코드**(`ABCD-EFGH` 같은 8자리)가 나와요. 링크와 코드는 같은 것이고, **10분 동안 한 번만** 쓸 수 있어요.

### 안드로이드

1. 폰 Slack에서 **📱 웹앱 열기**를 눌러 **크롬**에서 열어요. 바로 연결돼요.
2. 화면 위 **홈 화면에 추가** 버튼을 누르거나, 크롬 **⋮ → 홈 화면에 추가**(또는 **앱 설치**)를 눌러요.

### 아이폰

아이폰은 홈 화면 앱과 Safari가 **저장 공간을 따로** 써서, 홈 화면 앱 안에서 연결해야 해요.

1. 폰 Slack에서 **📱 웹앱 열기**를 눌러 **Safari**에서 열어요. Slack 안에서 열렸다면 메뉴에서 **Safari로 열기**를 눌러요.
2. Safari 아래쪽 **공유 버튼(⬆︎) → 홈 화면에 추가**를 눌러요.
3. 홈 화면에 생긴 **집중요정**을 열고, Slack 모달의 **연결 코드**를 입력해요.

:::tip
1번 화면에도 연결 코드가 크게 보여요. 홈 화면에 추가하지 않고 Safari에서 바로 쓰고 싶다면 그 아래 **Safari에서 쓸래요**를 누르면 돼요.
:::

### 여러 워크스페이스 쓰기

각 워크스페이스에서 `/settings app` 으로 코드를 받아 앱 위쪽 드롭다운의 **＋ 워크스페이스 추가**에 입력하면 돼요. 드롭다운으로 전환할 수 있어요.

## 화면

[크롬 익스텐션 팝업](/extension/#팝업-둘러보기)과 같은 기능을 폰 화면에 맞게 한 열로 보여줘요.

- **위쪽**: 지금 상태와 큰 시계, 카테고리, 계획, 메시지를 올릴 채널, 오늘 함께 집중한 팀원
- **시작·쉬어가기·종료 버튼**은 화면 아래쪽에 붙어 있어요
- **아래쪽**: 이번 달의 나무, 월 목표, 일별·누적 그래프, 카테고리 비율

앱을 다시 열거나 다른 앱에서 돌아오면 Slack에서 바꾼 상태가 바로 반영돼요.

## 맥에서 항상 위에 띄우기

컴퓨터에서도 웹앱을 작은 창으로 띄워둘 수 있어요. 다른 앱 창보다 **항상 위에** 떠 있어서, 작업하면서 내 타이머와 지금 집중 중인 팀원을 계속 볼 수 있어요.

1. 컴퓨터 **크롬**(또는 엣지)에서 `/settings app` 의 **📱 웹앱 열기**를 눌러 연결해요.
2. 오른쪽 위 **📌** 버튼을 눌러요. 작은 창이 떠요.
3. 창을 원하는 위치로 끌어다 두면 다음에도 그 자리에 떠요.

작은 창에서 시작·쉬어가기·종료를 할 수 있고, 팀원 현황은 30초마다 갱신돼요. 누가 새로 집중을 시작하면 잠깐 반짝여요.

:::note
- 작은 창은 원래 웹앱 창을 닫으면 같이 닫혀요. 크롬 **⋮ → 전송, 저장, 공유 → 페이지를 앱으로 설치**로 웹앱을 설치해두고, 그 창을 최소화해두면 편해요.
- 크롬과 엣지에서만 돼요. Safari에서는 📌 버튼이 보이지 않아요.
- 종료할 때 기록 시간을 직접 입력하려면 원래 웹앱 창에서 해주세요.
:::

## 익스텐션과 같이 쓰기

웹앱과 익스텐션은 **따로 연결**돼요. 웹앱을 다시 연결해도 익스텐션 연결은 그대로고, 그 반대도 마찬가지예요. 같은 세션을 폰에서 시작하고 컴퓨터에서 끝내도 돼요.

## 자주 묻는 질문

**알림도 오나요?**
아직은 없어요. 앱을 열면 지금 상태를 보여주는 방식이에요.

**"토큰이 유효하지 않아요"가 나와요.**
같은 워크스페이스의 웹앱을 다른 폰(또는 다른 브라우저)에서 다시 연결하면 이전 연결은 끊겨요. `/settings app` 으로 새 코드를 받아 ⚙︎ 에서 다시 입력해주세요.

**연결을 해제하고 싶어요.**
⚙︎ → **이 워크스페이스 연결 해제**를 누르면 폰에서 지워져요. 홈 화면에서 앱을 지워도 돼요.
