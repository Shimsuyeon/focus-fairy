워크스페이스에 다른 Slack 앱(예: Hermes Agent)이 설치되어 있고, 그 앱이 `/resume` 같은 같은 이름의 명령어를 등록하면 호출이 집중요정으로 오지 않을 수 있어요. Slack은 슬래시 명령어 우선순위를 사용자나 관리자가 설정할 수 없기 때문에, 이런 경우엔 집중요정의 **`/f`-prefix alias**를 사용하세요.

## alias 목록

| 기존 명령어 | alias | 설명 |
|---|---|---|
| `/start` | `/fstart` | 집중 시작 |
| `/end` | `/fend` | 집중 종료 |
| `/pause` | `/fpause` | 일시 정지 |
| `/resume` | `/fresume` | 재개 |

기존 명령어와 alias는 동일하게 동작해요. 인자도 그대로 받습니다 (예: `/fstart 코드리뷰`).

## 언제 사용하나요?

- 슬래시 명령어를 입력했는데 집중요정이 응답하지 않을 때
- 명령어가 다른 앱(예: Hermes Agent, GitHub, Jira 등)으로 라우팅된다는 메시지가 보일 때
- 워크스페이스에 다양한 봇이 깔려 있어 충돌을 미리 피하고 싶을 때

## 컨트롤 패널도 활용하세요

`/start`(또는 `/fstart`)를 실행하면 본인에게만 보이는 ephemeral 메시지로 **일시정지 / 종료 / 통계** 버튼이 함께 표시돼요. 슬래시 명령어 충돌을 신경 쓰지 않고 버튼만 눌러서 세션을 컨트롤할 수 있어요. 자세한 내용은 [/start 컨트롤 패널](/commands/start/#컨트롤-패널) 섹션을 참고하세요.

## 봇 운영자 안내 (자체 설치)

집중요정을 직접 운영하는 경우, Slack 앱 설정 페이지의 **Slash Commands** 섹션에 4개 alias(`/fstart`, `/fend`, `/fpause`, `/fresume`)를 등록해야 사용자가 호출할 수 있어요. 명령어 이름만 다르게 하고, 요청 URL은 기존과 동일하게 `/slack/commands`로 설정하면 됩니다. 백엔드 라우팅은 자동으로 처리돼요.

명령어 등록은 한 번만 하면 되고, 이후 설치되는 모든 워크스페이스에서 자동으로 사용할 수 있어요.
