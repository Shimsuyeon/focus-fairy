진행 중인 집중 세션을 종료하는 명령어예요. 종료 시점의 누적 시간이 통계에 반영돼요.

## 사용법

```
/end
```

다른 Slack 앱과 명령어가 겹칠 때는 `/fend`로도 같은 동작을 호출할 수 있어요. 자세한 내용은 [명령어 충돌 회피](/commands/aliases/)를 참고하세요.

종료하면 채널에 응원 메시지와 함께 세션 결과가 표시되고, Slack status는 자동으로 해제돼요.
