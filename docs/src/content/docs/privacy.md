집중요정(Focus Fairy)은 집중 시간을 기록하고 보여주는 데 꼭 필요한 정보만 다뤄요. 이 문서는 **집중요정 Slack 봇**과 **집중요정 크롬 익스텐션**에 함께 적용돼요.

시행일: 2026년 10월 22일 (10월 24일 개정: Slack status 조회, 운영용 합계 통계 추가)

## 수집하는 정보

### 집중요정 서버에 저장되는 정보

| 정보 | 용도 |
|---|---|
| Slack 워크스페이스 ID · 사용자 ID | 누구의 기록인지 구분 |
| 워크스페이스 이름 · 사용자 표시 이름 | 팝업·리포트에 이름 표시 (표시 이름은 하루 동안만 캐시) |
| 집중 세션 기록 (시작·종료 시각, 집중 시간, 쉬어간 시간, 계획, 카테고리) | 통계, 리포트, 랭킹 |
| 진행 중인 세션 상태 | 시작·일시정지·종료 처리 |
| `/start` 한 채널의 ID와 이름 (최근 10개) | 익스텐션에서 메시지를 올릴 채널 선택 |
| 월 목표 시간 | 이번 달의 나무, 목표 안내 |
| 익스텐션 연결 토큰의 **해시값** | 익스텐션 요청이 본인 것인지 확인 (토큰 원본은 저장하지 않아요) |
| 워크스페이스 설정 (자동 기록 임계값, 기본 시간대 등) | 세션 처리 |
| 워크스페이스에 설치된 봇 토큰 | Slack 메시지 발송, 사용자 이름 조회 |
| [Slack status 동기화](/settings/sync/) 연결 시 사용자 토큰 | status 변경 (연결한 사용자만) |
| 집중 시작 전 사용자가 직접 설정한 status, 집중요정이 마지막으로 표시한 status | 직접 설정한 status를 덮어쓰지 않고 집중이 끝나면 되돌리기 (status 동기화 연결자만, 되돌린 뒤 삭제) |

### 크롬 익스텐션이 브라우저에 저장하는 정보

익스텐션은 `chrome.storage.local`(이 브라우저 안)에만 아래 정보를 저장해요.

- 연결한 워크스페이스의 서버 주소, 연결 토큰, 워크스페이스·사용자 이름
- 워크스페이스별 채널 선택, 마지막 세션 상태(툴바 배지 표시용)

## 수집하지 않는 정보

- 방문한 웹사이트, 브라우징 기록, 탭 내용
- Slack 메시지 내용 (집중요정 명령어로 입력한 계획 외에는 읽지 않아요)
- 위치, 연락처, 결제 정보
- 광고·분석 도구를 쓰지 않아요

익스텐션의 content script는 **집중요정 연결 페이지**(`/extension/connect`)에서만 동작하고, 그 페이지의 일회용 연결 코드만 읽어요.

## 정보를 쓰는 곳

- 집중 시간 기록과 통계 (`/today`, `/weekly`, `/report`, App Home, 익스텐션 팝업)
- 같은 워크스페이스 팀원에게 보이는 정보: 집중 상태, 카테고리, 집중 시간, 랭킹. **계획 내용은 익스텐션의 팀원 현황에 보이지 않아요** (채널에 올라가는 시작·종료 메시지에는 포함돼요)
- 서비스 운영과 개선: 워크스페이스별 사용자 수, 일별·주별 사용 추이, 기능별 사용 비율 같은 **합계 통계**만 운영자가 확인해요. 계획 내용이나 개인별 기록은 보지 않아요.
- 정보를 판매하거나 광고에 쓰지 않고, 아래 처리 위탁 외에는 제3자에게 제공하지 않아요

## 처리 위탁

| 업체 | 내용 |
|---|---|
| Cloudflare (Workers, Workers KV) | 서버 실행, 데이터 저장 |
| Slack | 메시지 발송, 사용자 이름 조회, status 조회·변경 |

## 보관 기간과 삭제

- 집중 기록은 통계를 위해 별도 요청이 없으면 계속 보관해요.
- 익스텐션 연결은 팝업의 ⚙︎ → **연결 해제**로 브라우저에서 지울 수 있고, Slack에서 다시 연결하거나 토큰을 새로 받으면 이전 토큰은 바로 무효가 돼요.
- 익스텐션을 삭제하면 브라우저에 저장된 정보도 함께 지워져요.
- 기록 삭제를 원하면 [GitHub 이슈](https://github.com/Shimsuyeon/focus-fairy/issues)로 요청해주세요.

## 보안

- 서버와 익스텐션은 HTTPS로 통신해요. 웹스토어에서 설치한 익스텐션은 집중요정 서버에만 접근할 수 있어요.
- 연결 토큰과 일회용 연결 코드는 SHA-256 해시로만 저장하고, 연결 코드는 10분 뒤 만료돼요.
